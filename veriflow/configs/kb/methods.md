# 科研数据分析方法说明库

本文件是平台的"知识库"。它不是装饰：L3 比对用哪套口径、容差取多少、空值怎么算，
都以这里为准，验证证据里会写上命中的章节（ref=configs/kb/methods.md#小节名）。
评审可以直接翻到对应小节核对，不需要相信模型的措辞。

## 组间均值差口径

目标量：diff = mean(value | group=B) − mean(value | group=A)。

- 分组依据是 `group` 列的取值 A / B，注意 A、B 顺序不能颠倒：diff 定义成 B−A。
- 组内样本量分别记为 n_a、n_b。任一组的样本量不能为 0。
- 均值按算术平均计算，不加权、不截尾、不做鲁棒估计。
- 若同一 sample_id 出现多次，视为重复采样，进入清洗分支处理。

## 缺失值与单位

- `value` 为空字符串、空白、或无法解析为数字的行，一律不计入任何一组的均值，也不计入 n。
- 缺失值不做插补：插补会改变 diff，且插补方法是主观选择，无法作为可复现口径。
- 单位不统一（例如出现 `ug` 与 `mg` 混用）时，必须先折算到同一单位再计算；
  否则 L3 与基准真值的偏差会远大于容差，直接被拦下。
- 折算方向：1 mg = 1000 ug，统一折算到 mg。

## 验证判据与容差

五级判据，任一级不通过即整轮不通过：

- L1 结构：产物必须含 diff、n_a、n_b，且 n_a、n_b > 0。
- L2 可执行：脚本子进程 exit_code = 0。
- L3 基准真值比对：|平台 diff − 基准真值| ≤ 0.5（绝对容差，适用于本数据量级）。
- L4 交叉独立复算：平台结果与验证器独立实现的相对误差 ≤ 1e-9；
  且验证器内部两条路径（statistics.fmean 与手工累加）自洽。
- L5 人工放行：涉及对外结论或高风险场景时，由人签字，平台不自动放行。

严禁把"另一个 LLM 说它对"当作验证。L3 比的是**基准真值**，L4 比的是**另一条代码路径**，
两者都不是模型的意见。

## 自我循环与终止条件

- 循环状态机：执行 → 验证 → 诊断 → 修正 → 重执行。
- 三个终止条件必须同时成立才算合规：轮次上限（max_rounds）、预算上限、策略去重。
- 策略去重：同一失败类型已用过同一修复策略，就不再重复尝试，直接判 blocked 并说明原因。
- 能收敛、也能认输：数据本身有误且轮次用完时，输出 failed 并保留证据，不伪造通过。
