# 证据目录

这里的每份 `<用例>.md` 是该用例**一次完整运行**的汇总，由 `artifacts/<用例>/` 下的原始日志
按顺序拼接而成，没有删改：计划 → 就绪队列 → 调度决策 → 执行 → 验证 → 自循环 → 结果 → 报告。

想核对原始文件，在仓库根目录跑一遍即可重新生成：

```bat
python -m harness suite --mode all
```

原始日志会出现在 `artifacts/<用例>/`，文件名与本文件里的分节标题一一对应。

`suite_table.json` 是三档基线（单 Agent / 串行流水线 / 本平台）的逐条结果，
方案书 §7、PPT 第 10 页的数字都取自这里。
