> 任何改动都要留下可核对产物（artifacts/ + evidence/），否则等于没做。

## C. 不做

- 拖拽式可视化编排器（赛题非硬性，成本极高）
- 多用户 / 鉴权 / 数据库（这是作品不是 SaaS）

## D. 纪律

- **11/23–27 初赛评审期：仓库冻结**，一个 commit 都不推。
- 每次改动记版本号（v1.1、v1.2…），答辩时能讲清"三个月迭代了什么"。
- 数字只从 `artifacts/` 出，任何手改的指标一旦被追问就是灾难。
